# Changelog

## 0.1.0

Initial release candidate.

- Add a sidebar for editing directory-tree drafts without changing workspace files.
- Support inline names and comments, drag and drop, keyboard navigation, and undo/redo.
- Copy plain text or fenced Markdown, with a live text preview.
- Save one draft per workspace and support desktop and browser extension hosts.
- Follow the editor's light, dark, and high-contrast themes.
