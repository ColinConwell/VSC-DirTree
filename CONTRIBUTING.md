# Contributing

Use [GitHub Issues](https://github.com/ColinConwell/VSC-DirTree/issues) to report bugs or discuss a feature before starting a substantial change. Include the editor and operating-system versions, steps to reproduce, and expected behavior. Do not attach credentials or private workspace content.

Follow [Development and Testing](docs/development.md) to build and run the extension. Keep changes focused, preserve keyboard accessibility and editor themes, and add regression coverage when changing behavior. Run the type check, formatter check, relevant tests, and package verification before submitting a pull request.

Contributions are provided under the repository's GPL-3.0-only license. Preserve third-party copyright and license notices.

For concerns that should not be posted publicly, contact Colin Conwell at [colinconwell@gmail.com](mailto:colinconwell@gmail.com).
